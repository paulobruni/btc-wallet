## Wallet Generator

### Dependecies
* Node.js
* Your preferred BTC Waller UI (Electrum was used in this project)
* Bitcoin testnet faucet: https://coinfaucet.eu/en/btc-testnet/
* BItcoin testnet explorer: https://blockstream.info/testnet/

### Description

In this project you can generate your own address, mnemonic and private key, so this way you can test the bitcoin transference between differente wallets.
